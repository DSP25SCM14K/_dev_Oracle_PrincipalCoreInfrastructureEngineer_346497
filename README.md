# Dev Kumar — AI Infrastructure & HPC Portfolio

A responsive portfolio featuring an animated GPU/HPC cluster topology, workload delivery diagram, complete experience history, and project links.

Open `index.html` directly or serve this folder with a static web server. GitHub Pages deploys the static site from the repository root using the included Actions workflow.

- `index.html` — portfolio content and role-specific cluster diagram
- `styles.css` — responsive design and animation
- `script.js` — animated background, rotating focus text, reveals, and project filtering
